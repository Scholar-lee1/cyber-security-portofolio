## The Approach

Each activities follows this structure:
- **Execute:** Do the work (run commands, solve challenges, exploit vulnerabilities)
- **Understand:** Explain why it works
- **Document:** Screenshot + context + learning
- **Professional:** Clean repo, clear structure, portfolio-ready
