# Assignment 1: Linux Fundamentals — 100 Core Commands

## Overview

Mastering 100 essential Linux commands organized into 5 progressive categories. Each command is documented with understanding in mind: what it does, why it matters, real-world applications, and variations.

**Not memorization. Understanding.*

## Structure

### Category 1: File Management (20 commands)
Navigate, create, view, manipulate, analyze, and compress files and directories.

**Skills gained:** Filesystem navigation, file organization, data handling

[→ View Category 1](./CATEGORY_1_FILE_MANAGEMENT.md)

### Category 2: Permissions (20 commands)
Control access, manage ownership, handle user/group privileges, and secure files.

**Skills gained:** Permission model, security principles, access control

[→ View Category 2](./CATEGORY_2_PERMISSIONS.md)

### Category 3: Environment Variables (20 commands)
Manage shell variables, set paths, configure environment, and debug configuration.

**Skills gained:** Shell configuration, environment setup, automation

[→ View Category 3](./CATEGORY_3_ENVIRONMENT_VARIABLES.md)

### Category 4: User Administration (20 commands)
Create users, manage groups, handle authentication, and administer systems.

**Skills gained:** User management, system administration, multi-user concepts

[→ View Category 4](./CATEGORY_4_USER_ADMINISTRATION.md)

### Category 5: Processes (20 commands)
Monitor running processes, manage priorities, background jobs, and system performance.

**Skills gained:** Process monitoring, resource management, system optimization

[→ View Category 5](./CATEGORY_5_PROCESSES.md)

---

## Learning Approach

Each command follows this pattern:
- **What it does:** Core function
- **Why it matters:** Real-world application
- **Example:** Actual usage

Commands are organized **progressively within each category**—building on each other like a story. Orientation → Creation → Viewing → Manipulation → Analysis → Advanced.
