**Steps:**
1. Log in to DVWA
2. Navigate to **DVWA Security** (bottom left)
3. Select difficulty: **Low** | **Medium** | **High** | **Impossible**
4. Click **Submit**

Each vulnerability can be tested at all 4 levels independently.
